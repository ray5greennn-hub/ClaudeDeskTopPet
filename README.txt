==============================
 Claude 桌宠 / Claude Desktop Pet
==============================

【中文】

▶ 怎么玩
  双击 ClaudeDeskTopPet.exe 就能启动，不需要安装任何东西。
  小家伙会出现在任务栏上方走来走去。

▶ 运行环境
  Windows 10 / Windows 11（系统自带的 .NET Framework 4.x 就够了）。
  只有这一个 exe，可以放在任何文件夹里。

▶ 第一次打开时如果被 Windows 拦住
  因为这个 exe 没有数字签名，Windows 可能会弹出“Windows 已保护你的电脑”。
  点「更多信息」→「仍要运行」即可。

▶ 基本操作
  · 左键点它：跳一下 / 叫醒 / 拆礼物 / 敲冰块
  · 左键拖动：拎起来；拖到屏幕左右边缘会吸在墙上
  · 右键：喂食、动作、玩游戏、洗澡、跟着鼠标跑、设置、拜拜（退出）

▶ 能做的事
  · 摸头：鼠标在它头上左右来回蹭，边走边摸也可以
  · 待机小动作：想一想、溜溜球、喝热茶、扫地、打喷嚏……扒在墙上也会挥手、打盹、偷吃饼干
  · 36 种食物，每种吃法不一样（面条用筷子嗦、薯条一根一根吃、龙虾一口吞）；还能配最多 3 样的套餐
  · 6 个游戏：踢足球、毛线球、顶气球、扔飞盘、戳泡泡、激光笔
  · 洗澡：花洒放水 → 肥皂搓澡 → 冲干净 → 浴巾擦干，沐浴露可以起泡泡
  · 装扮：帽子 / 眼镜 / 围巾 / 外套，共几十件
  · 小窝：5 种窝、8 种颜色、5 种花纹、9 种装饰、玩偶；在窝里会敲代码、看书、打游戏、看电影、听歌，困了就睡
  · 背景和灯光：小屋 / 草地 / 星空，窗外会下雨打雷下雪；夜里小窝会发暖光
  · 每小时有 30% 的概率给你送一份小礼物，点一下可以拆开
  · 中文 / English 切换

▶ 存档在哪 / 怎么卸载
  设置和装扮保存在：%APPDATA%\ClaudePet\config.txt
  卸载：删掉 exe，再删掉上面这个 ClaudePet 文件夹就干净了。

▶ 自己从源代码编译
  打开「源代码」文件夹，双击 build.bat，会在上一层生成新的 ClaudeDeskTopPet.exe。
  用的是 Windows 自带的 C# 编译器，不需要安装 Visual Studio。

【English】

▶ How to play
  Double-click ClaudeDeskTopPet.exe. Nothing to install.
  The little guy walks around above your taskbar.

▶ Requirements
  Windows 10 / 11 (the built-in .NET Framework 4.x is enough). Just one exe.

▶ If Windows blocks it the first time
  The exe is not code-signed, so SmartScreen may say "Windows protected your PC".
  Click "More info" → "Run anyway".

▶ Controls
  · Left-click: jump / wake up / open a gift / crack the ice
  · Drag: pick it up; drop it at the left or right screen edge to stick it to the wall
  · Right-click: Feed, Actions, Games, Bath, Follow the mouse, Settings, Bye (quit)

▶ Settings & uninstall
  Settings are saved in %APPDATA%\ClaudePet\config.txt.
  To uninstall, delete the exe and that ClaudePet folder.

▶ Build from source
  Open the 源代码 (source) folder and double-click build.bat.
